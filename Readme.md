# Health Prediction Application

## Project Overview

This application predicts possible health risks based on patient blood test values and stores patient information in a MySQL database.

## Features

* Create Patient Records
* View Patient Records
* Update Patient Records
* Delete Patient Records
* Health Risk Prediction
* MySQL Database Integration
* Streamlit User Interface
* Input Validation

## Technologies Used

* Python
* Streamlit
* MySQL
* Pandas

## Database Fields

* Full Name
* Date of Birth
* Email Address
* Glucose
* Haemoglobin
* Cholesterol
* Remarks

## How to Run

1. Install requirements:

pip install streamlit pandas mysql-connector-python

2. Run the application:

python -m streamlit run app.py
